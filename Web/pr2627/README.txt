Запуск
1. Відкрийте термінал у цій папці
2. Виконайте: node server.js
3. Відкрийте http://127.0.0.1:8027 у браузері
4. Відкрийте http://127.0.0.1:8027/list.html щоб отримати список запмовлень
Для зупинки сервера натисніть Ctrl+C у терміналі
Подвійне натискання index.html не запускає сервер: для збереження потрібен запуск server.js

Поля та правила
- Отримувач і адреса доставки — обов'язкові непорожні рядки.
- Вага, довжина, ширина й висота — обов'язкові скінченні числа більше нуля.

Робота сторінки
- change перевіряє поле й показує помилку та червону рамку.
- input прибирає повідомлення й виділення помилки під час редагування.
- «Зберегти» перевіряє всі поля та надсилає JSON методом POST на /PostService.
- Локальний PostService повторно перевіряє дані й зберігає відправлення у parcels.json, який створюється після першого збереження.
- «Скасувати» відкриває list.html зі списком збережених відправлень без збереження змін.
- Посилання «Редагувати» у списку відкриває наявне відправлення; повторне збереження оновлює його, а не створює копію.
- Реальну адресу PostService у завданні не вказано, тому реалізовано мінімальний локальний сервер на Node.js без додаткових пакетів.
