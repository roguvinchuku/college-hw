Практична робота №19
Контрольні запитання

1. Що таке JavaScript та для чого використовується ця мова програмування?
JavaScript — мова програмування, за допомогою якої створюють інтерактивні вебсторінки: обробляють дії користувача, змінюють вміст і виконують обчислення. Її також використовують на сервері, наприклад у середовищі Node.js.

2. Які основні відмінності між JavaScript та Java?
Це окремі мови програмування. JavaScript має динамічну типізацію та прототипне успадкування. Java має статичну типізацію й успадкування на основі класів; її код зазвичай компілюють у байткод для виконання у JVM. JavaScript у браузері виконує рушій JavaScript.

3. Яку роль відіграє JavaScript у клієнтській частині вебзастосунків?
JavaScript реагує на натискання кнопок та інші події, перевіряє введені дані, змінює елементи сторінки через DOM і надсилає запити до сервера без повного перезавантаження сторінки.

4. Які типи даних підтримує JavaScript?
Примітивні типи: number, bigint, string, boolean, undefined, symbol і null. Окремий тип object охоплює об'єкти, зокрема масиви та функції. Оператор typeof для null повертає "object", але null є примітивним значенням.

5. Чим відрізняються способи оголошення змінних let, const та var?
let має блокову область видимості та дозволяє повторне присвоєння значення.
const також має блокову область видимості, але потребує початкового значення й забороняє повторне присвоєння. Властивості об'єкта або елементи масиву, оголошеного через const, можна змінювати.
var має область видимості функції або глобальну, а не окремого блоку, та допускає повторне оголошення. До рядка оголошення var має значення undefined; звернення до let чи const до їх ініціалізації спричиняє ReferenceError.
